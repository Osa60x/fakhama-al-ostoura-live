# Brand spec — فخامة الأسطورة

## Visual direction
Quiet editorial luxury for an Arabic gold-price salon: obsidian mineral surfaces, champagne gold, parchment typography, and measured motion.

## Assets
- `/public/luxury-hero.jpg` — original generated hero campaign image; 16:9.
- `/public/collection-necklace.jpg` — original generated collection image; 4:5.
- `/public/collection-ring.jpg` — original generated collection image; 4:5.
- `/public/favicon.svg` — existing project mark.
- Runtime store logo remains data-driven through the Supabase branding path when configured.

## Tokens
- Obsidian: `#11100e`
- Mineral: `#1b1915`
- Champagne: `#d6ad62`
- Parchment: `#efe3cf`
- Muted sage: `#a6b4a0`

## Typography
- Arabic UI: Cairo, with system fallback.
- Editorial emphasis: DM Serif Display, with Georgia fallback.

## Motion
- Editorial reveal on first viewport.
- 220–800ms interaction easing.
- Slow ambient light remains subtle.
- `prefers-reduced-motion: reduce` disables decorative movement.
